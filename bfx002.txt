Break-fix activity
Objectives
Investigate why the migrated web application is failing to load the landing page.

Solve the landing page issue from web application in a hands-on lab environment.

Scenario
Your team is facing a massive problem with a new production deployment and it is affecting the company's management. Your team migrated a customized application from server to OpenShift, and it is failing. Web server is not showing the landing page and your team is receiving complaints for the same. Your job is to make the landing page of the web server up and running as soon as possible.

After migrating the application pods are running but unable to access the web page:
